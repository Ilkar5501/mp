# Manual Clan Contest formations — v11.3.5

From v11.3.4, stop the bot, replace these six runtime files from GitHub main, and restart:

- VERSION
- data/characters.json
- hiq/contest.py
- hiq/battle/engine.py
- hiq/cogs/contest.py
- hiq/contest_render.py

Keep your database and .env. No dependency changes. The complete runtime ZIP includes earlier releases.

All requested support replacements are applied; team 1 is unchanged. The two Kageyama variants are allowed together only in the passive support formations. Prodigious Talent support keeps Open Play on its eligible featured unit through actions instead of alternating turns. Oikawa receives front Korai's Def/Jmp bonus; Osamu receives front-line Miracle Maker buffs; Kanoka receives back-line Miracle Maker buffs. Kai supplies both B and C to Iwaizumi from the back line.

Kai B now covers applicable targeting-draw skills (Iwaizumi, front Tsuki and back Komi) as well as actual saves by skills or Ultimates, in ordinary battles too. Forced targeting that bypasses the draw modifier does not qualify. Saves and draw skills do not double the +5 bonus; Fukunaga still disables external support. Kai's card text explains these conditions.

Discord previews show the contest-specific exceptions, and support icons include character titles to distinguish both Kageyamas. CLAN-CONTEST-TEAMS.md lists every support, position, active slot and exception.

The existing 14-day rotation order is retained. New attempts use the new formations; interrupted attempts use their saved formation revision. Existing scores, best daily results and rewards are retained.
